# Changelog

What each release of this plugin changes, newest first. The build copies this file into the jar, and Studio's
upgrade dialog shows the sections between the version a bot is on and the one it moves to. Keep the headings in
this shape (`## [1.2.0] — 2026-11-02`): a heading that is not a version, like `[Unreleased]`, is never shown.

Say what a bot's author has to redo after an upgrade: a managed value you renamed or reshaped is reset, not
converted.
